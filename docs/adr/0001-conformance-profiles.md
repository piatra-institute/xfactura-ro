# Coverage is defined by conformance

Planning decision; this records intended direction and does not claim implementation.

## Decision

Use draft-to-released, versioned conformance profiles and tested compositions. Treat the €1M figure as audience segmentation.

## Rationale

Revenue does not predict accounting complexity. Independent profiles make claims reproducible across implementations and separate workflow milestones from full-company replacement.

## Consequences

Profile compatibility, annual obligations and corpus versions must be explicit. The specification permits compatible competitors. [CONFORMANCE.md](../CONFORMANCE.md) owns the contract.

## Revisit condition

Revisit profile boundaries when real cases reveal a missing interaction; change revisions rather than mutating published claims.
