# Implementation and verification

The accounting specifications remain in [ACCOUNTING_PLATFORM_PLAN.md](ACCOUNTING_PLATFORM_PLAN.md). This file owns executable work and verification evidence. The current increment supports explicitly classified service price charges in original domestic invoices, including those with commercial allowances. API/MCP reconciles line value minus allowances plus charges to the net/VAT basis and retains each charge's source reason and amount. The existing review shows that breakdown and exact effects. Payments, later credits/refunds and closed earlier periods preserve original facts and approvals. It does not establish a full Romanian accounting suite or produce official declarations. [ACCOUNTING_ENGINE.md](ACCOUNTING_ENGINE.md) owns implemented contracts and limits.
